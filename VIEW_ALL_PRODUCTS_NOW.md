## 🎬 Features You Can Try

### 1️⃣ **Search Products**
- Type any product name
- Real-time filtering
- Works across all categories

### 2️⃣ **Filter by Status**
- Select: All, Published, Draft, Archived
- Table updates instantly

### 3️⃣ **Sort Products**
- Sort by: Newest, Oldest, Name (A-Z)
- All categories auto-sort

### 4️⃣ **Expand/Collapse Categories**
- Click category header to toggle
- See product count per category

- Click "Export CSV" button
- Downloads all visible products
- Includes: Category, Name, Type, Status, Featured, Created Date

- 👁️ **View** - See on website

- 📋 **Duplicate** - Clone product
- 🗑️ **Delete** - Remove product
